# Формат Excel для импорта Svet22

## Поддерживаемый файл

- Формат: `.xlsx`.
- Один файл относится строго к одному филиалу.
- Филиал администратор выбирает в панели до загрузки.
- Один файл — один снимок ассортимента/остатков филиала на дату импорта.
- Максимальный размер: 5 МБ (лимит также задаётся в PHP-конфигурации и Apache).
- Заголовки должны находиться в первой строке.

## Обязательные колонки

| Колонка | Обязательность | Назначение | Правило |
|---|---|---|---|
| Штрихкод | желательно | Идентификатор товара | Строка, ведущие нули сохраняются |
| Артикул | желательно | Внутренний код товара | Строка |
| Название | да | Наименование | Не пустое |
| Цена | да | Текущая цена филиала | Число, неотрицательное |
| Остаток | да | Количество в филиале | Число, неотрицательное |
| Единица измерения | желательно | шт., кг, л и т. п. | Строка |
| Категория | желательно | Категория каталога | Строка; при отсутствии создаётся |
| Производитель | желательно | Производитель | Строка |

Колонка `№` не используется как идентификатор и может отсутствовать. Порядок колонок не фиксируется: сопоставление выполняется по названиям заголовков. Для устойчивого сопоставления желательно использовать приведённые выше названия без переименования.

Должен быть хотя бы один идентификатор — штрихкод или артикул. Если есть оба, они должны ссылаться на один и тот же товар.

## Результат проверки приложенного файла

Файл `Таблица.xlsx` содержит лист `Лист1`, заголовки из 9 колонок и 4 заполненные товарные строки. После четвёртой строки есть пустые строки — парсер должен игнорировать их. В нём нет даты снимка, поэтому дату импорта задаёт сервер в часовом поясе проекта (Asia/Barnaul) при нажатии «Импортировать».

Обратите внимание: примеры значений штрихкодов в файле похожи на тестовые и имеют разную длину. Они подходят для проверки импорта, но не подтверждают, что это реальные штрихкоды товаров.

## Правила обработки

1. Пустые строки пропускаются.
2. Название, цена и остаток обязательны.
3. Цена и остаток должны быть числовыми и неотрицательными.
4. Строка без обоих идентификаторов (штрихкод и артикул) пропускается с записью ошибки.
5. Дубликаты идентификатора внутри одного файла не должны молча перезаписывать друг друга: конфликтные строки попадают в журнал ошибок.
6. Некорректная строка не останавливает обработку остальных строк.
7. Остаток 0 означает «нет в наличии».
8. Импорт файла филиала A не изменяет остаток или цену филиала B.
9. Отсутствие товара в новом файле само по себе не означает нулевой остаток: это правило требует отдельного подтверждения формата выгрузки. До подтверждения отсутствующие строки не обнуляются.
10. Повторный импорт того же файла не создаёт дублей товаров и записей истории за одну дату.
