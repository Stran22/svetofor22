# Светофор — Android

Нативное Android-приложение продуктового магазина «Светофор», разработанное на Kotlin и Jetpack Compose.

Приложение взаимодействует с сервером PHP + MySQL, показывает ассортимент, цены и наличие товаров по филиалам. Корзина и оформление покупок не предусмотрены.

## 1. Среда разработки

- Android Studio Panda 4
- JDK 17
- Gradle Wrapper 8.7
- Android Gradle Plugin 8.6.1
- Kotlin 2.0.0
- Android SDK 34
- Windows, подключение Android-телефона через USB

Версии инструментов приведены по ранее сохранённой конфигурации. При изменении Gradle-файлов документацию необходимо актуализировать.

## 2. Репозиторий

GitHub: https://github.com/Stran22/svetofor22

Рабочая ветка Android: `android`

Локальная папка проекта:

`D:\GitHub\svetofor22\android`

В Git не должны включаться результаты сборки, каталоги `.gradle`, `build` и локальные конфигурационные файлы.

## 3. Серверная часть

Адрес API:

`https://baza.altaj-otdyh.ru/api/v1/`

Сервер использует PHP и MySQL.

Основные функции API:

- Получение списка филиалов.
- Получение категорий с полем `parent_id`.
- Получение товаров по филиалу.
- Авторизация пользователей.
- Работа с отзывами.
- Регистрация устройств для push-уведомлений.
- Управление подписками на появление товаров.

Доступность каждого API-метода необходимо проверять при интеграционном тестировании.

## 4. Реализованные и проверенные функции

### Каталог товаров

- Загрузка категорий с сервера.
- Иерархическая навигация по категориям.
- Поддержка трёх уровней вложенности.
- Переход из категории к списку товаров.

Проверенный пример:

Каталог → Мясо и птица → Колбасы и мясные деликатесы → Колбасы → Товары.

### Сборка приложения

- Проект успешно компилируется в Android Studio.
- Приложение установлено и запущено на физическом Android-телефоне.
- Навигация по трём уровням категорий проверена на устройстве.

## 5. Реализованные компоненты, требующие дальнейшей проверки

- Выбор филиала.
- Поиск товаров.
- Карточка товара и отображение наличия.
- Авторизация пользователей.
- Отзывы и рейтинги.
- Регистрация FCM-токена.
- Push-уведомления.
- Подписки на появление товаров.

Наличие программного кода не означает, что весь сценарий работы функции уже прошёл тестирование.

## 6. Открытие проекта

1. Запустить Android Studio.
2. Открыть папку `D:\GitHub\svetofor22\android`.
3. Проверить использование Gradle Wrapper и JDK 17.
4. Дождаться Gradle Sync.
5. Выполнить Build → Make Project.
6. Подключить телефон через USB.
7. Запустить приложение кнопкой Run.

## 7. Правила работы с Git

Перед обновлением проекта проверять состояние репозитория:

```powershell
git status -sb
```

Получение изменений:

```powershell
git pull --ff-only origin android
```

Отправка подготовленных и сохранённых коммитов:

```powershell
git push origin android
```

Не добавлять в Git результаты сборки Android.

Не восстанавливать весь `stash` без предварительного анализа его содержимого.
